## 术语

| 术语 | 含义 |
|---|---|
| WA / WAuxiliary | 宿主 LSPosed 模块 `me.hd.wauxv`，本插件运行在它的插件运行时里 |
| BeanShell 脚本 | WA 按 BeanShell 规则执行 `.java` 文件；本项目所有模块都是这类脚本，**不是普通 Java 类** |
| `SnsInfo` | 微信朋友圈数据库 `SnsMicroMsg.db` 中的动态表 |
| `snsId` | 一条朋友圈的全局 ID（64 位，可能为负） |
| `localId` | 一条朋友圈在 `SnsInfo` 表中的本地行号（即 rowid），用于精确跳转 |
| 关注名单 | 用户选择的、需要提醒的好友 `wxid` 集合 |
| 去重账本 | 已提醒过的 `snsId` 集合，保证同一条动态只提醒一次 |
| 监视起点 | 本次插件加载的时刻。早于它的动态视为历史数据，不提醒 |
